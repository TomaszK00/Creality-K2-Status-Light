# Contributing

Thanks for helping improve Creality K2 Status Light!

## Report a bug or request a feature

Open a GitHub Issue. Provide:
- Firmware version (if known).
- ESP32 model and LED configuration.
- What happened, what you expected, and clear reproduction steps.
- Relevant logs/screenshots **with passwords, Wi-Fi credentials, access tokens and private IP information redacted where appropriate**.

## Propose a code change

1. Fork the repository.
2. Create a topic branch in your fork.
3. Explain your change and how you tested it.
4. Open a pull request to propose a change for maintainer review.

**Pull requests are proposals, not direct edits to the upstream repository.** Repository maintainers decide what is merged.

## Safety and code quality

Avoid committing secrets, real Wi-Fi passwords, tokens, or personal data. Do not publish unverified pinouts or power supply designs. Test firmware and OTA changes on real supported hardware before proposing release.
