# Release and OTA checklist

The active OTA manifest is at [`Software/update.json`](../Software/update.json) and currently points to the **v2.27 test candidate**. Archived **v2.16** remains unpromoted. **Keep the manifest format and path unchanged unless the updater firmware is updated too.**

## Preparing a new version

1. Build and test firmware on the supported ESP32 hardware.
2. Export the OTA-compatible `.bin` using the **same compatible partition and firmware layout** as existing deployed devices.
3. Name it consistently, e.g. `K2_Status_Light_v2_17_OTA.bin`.
4. Upload the binary to `Software/` *before* updating the manifest.
5. Compute the actual binary byte size and SHA-256 checksum.
6. Update `Software/update.json` with the new version, exact filename, byte size and lowercase SHA-256.
7. Verify the binary URL, checksum, update detection and actual OTA installation before announcing the release.
8. Update [CHANGELOG.md](../CHANGELOG.md); optionally create a GitHub Release with notes and checksums.

## Manifest format

```json
{
  "version": "2.27",
  "file": "K2_Status_Light_v2_27_OTA.bin",
  "size": 1685904,
  "sha256": "e23529d49bd455efce98a592939678764b0d9866a55fa6a1db3e88dd7e8f9fd1"
}
```

This is the manifest **as currently published**, not a proof that the binary was validated. Storing a higher version in `Software/archive/` does not activate it. Version 2.27 is explicitly a test candidate generated by GitHub Actions. Its build, size and checksum were checked, but installation and printer behavior still need hardware testing. For stable releases, validate the installation on hardware before marking a version stable. Keep older known-good firmware files available for recovery where appropriate.

## v2.27 compatibility

The same firmware is available as `Software/LayerGlow_v2_27_OTA.bin` and the legacy alias `Software/K2_Status_Light_v2_27_OTA.bin`. The manifest points to the legacy alias because v2.25 only recognizes that naming pattern. Older installed firmware may use the former raw GitHub URL after the repository rename; if the old updater fails to fetch the image, use the manual OTA upload once, then later updates use the LayerGlow URL.
