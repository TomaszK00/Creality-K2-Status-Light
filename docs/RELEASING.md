# Release and OTA checklist

The active OTA manifest is at [`Software/update.json`](../Software/update.json) and currently points to the **v2.32 test candidate**. Archived **v2.16** remains unpromoted. **Keep the manifest format and path unchanged unless the updater firmware is updated too.**

## Preparing a new version

1. Build and test firmware on the supported ESP32 hardware.
2. Export the OTA-compatible `.bin` using the **same compatible partition and firmware layout** as existing deployed devices.
3. Name it consistently, e.g. `LayerGlow_v2_33_OTA.bin`.
4. Upload the binary to `Software/` *before* updating the manifest.
5. Compute the actual binary byte size and SHA-256 checksum.
6. Update `Software/update.json` with the new version, exact filename, byte size and lowercase SHA-256.
7. Verify the binary URL, checksum, update detection and actual OTA installation before announcing the release.
8. Update [CHANGELOG.md](../CHANGELOG.md); optionally create a GitHub Release with notes and checksums.

## Manifest format

```json
{
  "version": "2.32",
  "file": "LayerGlow_v2_32_OTA.bin",
  "size": 1705520,
  "sha256": "e7c8d2a39ff7903eabe996307649d648999ae770634b1f49614b1d317bd331ae"
}
```

This is the manifest **as currently published**, not a proof that the binary was validated. Storing a higher version in `Software/archive/` does not activate it. Version 2.32 is explicitly a test candidate generated by GitHub Actions. Its build, size and checksum were checked, but installation and printer behavior still need hardware testing. For stable releases, validate the installation on hardware before marking a version stable. Keep older known-good firmware files available for recovery where appropriate.

## v2.32 compatibility

The manifest points to only `Software/LayerGlow_v2_32_OTA.bin`. The duplicate K2-named aliases from v2.27–v2.31 were removed from `Software/`; their LayerGlow-named binaries remain available. Older firmware that expects the historical filename pattern or repository URL may require a one-time manual OTA upload. Installation on a physical ESP32-C3 remains to be checked.
