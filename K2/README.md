# K2 — 3D printable parts (planned)

This folder will hold **future 3D models** for mounting and protecting the Creality K2 Status Light hardware. **No tested printable model is published yet.**

## Planned designs

| Design | Intended function | Status |
|---|---|---|
| LED bar housing | Enclosure/diffuser holder for progress LEDs | Planned |
| ESP32 electronics case | Protected compartment for ESP32 and cabling | Planned |
| Printer mounting clips | Mount LED bars without interfering with printer operation | Planned |
| Cable guides | Route and secure low-voltage LED cables | Planned |
| LED diffuser | Improve appearance and light uniformity | Planned |

These are concepts, not promised fit-tested parts. Dimensions, fastening methods, screw sizes, heat clearance and printable material choices are **to be verified** before any release.

## Suggested folder layout (when designs exist)

```text
K2/
  README.md
  models/
    STL/
    STEP/
    3MF/
  drawings/
  photos/
```

Each published model should have a description, printer compatibility, source CAD file when available, dimensions, printing orientation, material guidance, assembly photos and a revision number.
